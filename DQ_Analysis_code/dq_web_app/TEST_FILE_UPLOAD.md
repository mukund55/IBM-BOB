# File Upload Feature - Test Guide

## Overview
This guide will help you test the newly implemented file upload and DQ analysis feature.

## Prerequisites
- Flask application running on http://localhost:5000
- Sample CSV file ready for upload (e.g., `sample_customer_data.csv`)

## Test Workflow

### Step 1: Login
1. Open browser and navigate to: **http://localhost:5000**
2. Login with credentials:
   - Username: `admin`
   - Password: `admin123`
3. You should be redirected to the dashboard

### Step 2: Navigate to Upload Page
1. Click on **"Upload & Analyze"** in the navigation menu
2. You should see the file upload page with:
   - Drag-and-drop zone
   - File selection button
   - Supported formats listed (CSV, Excel, JSON, XML, DAT)

### Step 3: Upload a File
**Option A: Drag and Drop**
1. Drag a CSV file from your file explorer
2. Drop it onto the upload zone
3. File name should appear in the zone

**Option B: Click to Select**
1. Click the "Choose File" button
2. Select a CSV file from the file dialog
3. File name should appear in the zone

### Step 4: Start Analysis
1. Click the **"Analyze Data Quality"** button
2. You should see:
   - Progress indicator
   - "Analyzing..." message
   - The button becomes disabled during analysis

### Step 5: View Results
1. After analysis completes (may take 10-60 seconds depending on file size):
   - Success message appears
   - You're automatically redirected to the results page
2. On the results page, you should see:
   - Run summary (ID, filename, timestamp, status)
   - Overall DQ score
   - Key metrics (completeness, accuracy, consistency, etc.)
   - Embedded DQ dashboard (the HTML generated by data_quality_analysis.py)

### Step 6: Verify Dashboard
1. Scroll down to see the embedded dashboard
2. The dashboard should display:
   - Quality score gauge
   - Issues by category chart
   - Column-level metrics
   - Anomaly details
   - Recommendations

## Troubleshooting

### Issue: File Upload Fails
**Check:**
- File size (max 100MB by default)
- File format (must be CSV, Excel, JSON, XML, or DAT)
- File permissions

### Issue: Analysis Fails
**Check:**
- `data_quality_analysis.py` script exists in parent directory
- Python dependencies installed (pandas, numpy, etc.)
- Check terminal logs for error messages

### Issue: Dashboard Not Displaying
**Check:**
- `dq_executive_dashboard.html` was generated in output folder
- File path in database matches actual file location
- Browser console for JavaScript errors

### Issue: "No module named 'pandas'" Error
**Solution:**
```bash
pip install pandas numpy matplotlib seaborn openpyxl
```

## API Endpoints Used

### Upload Endpoint
- **URL:** `/api/analysis/upload`
- **Method:** POST
- **Content-Type:** multipart/form-data
- **Parameters:** 
  - `file` (required) - The file to upload
  - `config_file` (optional) - Custom DQ config JSON

### Results Endpoint
- **URL:** `/results/<run_id>`
- **Method:** GET
- **Returns:** HTML page with embedded dashboard
